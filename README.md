# ค้นหาสินค้า

จัดทำโดย **เฟย**

เว็บแอปค้นหาสินค้าวัสดุก่อสร้าง พิมพ์ชื่อ คำพ้อง ขนาด หรือการใช้งานก็หาเจอ แสดงผลเป็นกราฟ คำค้น → กลุ่มสินค้า → สินค้า พร้อมราคา, CODE, ภาพสินค้า และตะกร้ารวมราคา

## ความสามารถ

- **ค้นหาแบบยืดหยุ่น:** ใช้คำพ้องจากไฟล์กลุ่ม เช่น `DB12` → เหล็กข้ออ้อย, `ไวเมท` → ไวร์เมช จับคำสะกดผิดได้ แปลงหน่วย (2 หุน = 6 มม.) และค้นจากคำอธิบายหรือการใช้งาน เช่น `ทำโครงหลังคา`
- **กราฟแบบโต้ตอบได้ (D3.js):** ลาก ซูม คลิกกลุ่มหรือสินค้าได้ กลุ่มที่ "ซื้อคู่กัน" แสดงเป็นเส้นประ
- **รายละเอียดสินค้า:** ราคา, CODE, บาร์โค้ด, จำนวนคงเหลือ
- **ภาพสินค้า:** ใส่ลิงก์ (แสดงผ่าน iframe หรือ img) หรืออัปโหลดไฟล์ภาพ ภาพเก็บไว้ในเบราว์เซอร์ของผู้ใช้
- **ตะกร้า:** ปรับจำนวน รวมราคา และคัดลอกรายการได้
- **ค้นหาบ่อย:** นับคำค้นและสินค้าที่ถูกเปิดดูหรือใส่ตะกร้า แสดงเป็นปุ่มคำค้นบ่อย รายการสินค้ายอดนิยม และกราฟยอดนิยมในหน้าแรก สถิติเก็บแยกตามเบราว์เซอร์ของแต่ละคน

ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ทุกอย่างทำงานในเบราว์เซอร์

## โครงสร้างไฟล์

```
index.html             หน้าเว็บ
assets/style.css       หน้าตา
assets/app.js          ระบบค้นหา กราฟ ตะกร้า
data/products.js       ข้อมูลสินค้าและกลุ่ม (สร้างจากสคริปต์)
scripts/build_data.py  สคริปต์แปลง Excel + CSV → data/products.js
```

## เปิดใช้งานบนเครื่อง

ดับเบิลคลิก `index.html` ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด D3.js และฟอนต์)

## ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
   ```bash
   git init
   git add .
   git commit -m "ค้นหาสินค้า"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
   git push -u origin main
   ```
2. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
3. รอประมาณ 1 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

> **หมายเหตุ:** ข้อมูลใน `data/products.js` (ราคาขายและจำนวนคงเหลือ) จะเปิดดูได้โดยทุกคนที่มีลิงก์ ถ้าไม่อยากเปิดเผย ให้ใช้ repository แบบ private ร่วมกับแผนที่รองรับ Pages แบบ private หรือนำไปวางบนเซิร์ฟเวอร์ภายในแทน

## อัปเดตข้อมูลสินค้า

เมื่อแก้ไฟล์กลุ่ม/คำพ้อง (Excel ชีต `กลุ่ม`) หรือส่งออกสินค้า (CSV) ใหม่:

```bash
pip install pandas openpyxl
python scripts/build_data.py path/to/กลุ่ม.xlsx path/to/products_export_with_group.csv
git add data/products.js && git commit -m "อัปเดตข้อมูลสินค้า" && git push
```

**รูปแบบไฟล์ที่ต้องใช้**
- **Excel ชีต `กลุ่ม`:** คอลัมน์ `กลุ่ม`, `คำพ้อง` (คั่นด้วย `,`), `ประเภทงาน`, `ซื้อคู่กัน` (คั่นด้วย `,`), `คำอธิบาย`
- **CSV สินค้า:** คอลัมน์ `CODE`, `NAME`, `BARCODE`, `UNIT_TYPE`, `PRICE_1`, `STK_ONHAND`, `กลุ่ม`

**เคล็ดลับ**
- เติมคำพ้องให้กลุ่มที่ยังไม่มี โดยเฉพาะกลุ่มไม้ที่มีสินค้ามากที่สุด จะทำให้ค้นเจอง่ายขึ้นมาก
- ส่งออก CSV โดยตั้งคอลัมน์ `CODE` และ `BARCODE` เป็นข้อความ เพื่อไม่ให้กลายเป็น `3.62201E+12`
